# Telegram AI Auto-Reply

Это учебный автоответчик для личного Telegram-аккаунта на Python.

## Важно

- Не передавай никому `API_HASH`, `GEMINI_API_KEY` или код входа Telegram.
- Telegram API Terms требуют соблюдать правила платформы. Эта версия специально запрашивает согласие собеседника перед передачей его сообщений в AI-сервис.
- Не используй проект для массовых рассылок, спама или обхода ограничений Telegram.
- Для постоянной работы бесплатный Replit не гарантирует 24/7 uptime. На бесплатном тарифе лучше сначала тестировать проект; постоянный сервер может потребовать платный deployment/другой хостинг.

## Переменные Secrets

Добавь в Replit Secrets:

API_ID = твой числовой api_id
API_HASH = твой api_hash
GEMINI_API_KEY = твой ключ Gemini

Не записывай секреты прямо в код.

Дополнительно можно задать:

GEMINI_MODEL = gemini-2.5-flash
REPLY_DELAY_MIN = 3
REPLY_DELAY_MAX = 7
MAX_HISTORY = 8
SYSTEM_PROMPT = твой стиль ответов

## Запуск

1. Создай Python Repl.
2. Загрузите эти файлы.
3. Установи зависимости:
   pip install -r requirements.txt
4. Нажми Run.
5. При первом запуске Telethon попросит номер телефона, код Telegram и (если включён) пароль 2FA.
6. После авторизации появится файл сессии. Никому его не отдавай: он позволяет авторизоваться в аккаунте.
7. При следующих запусках повторный код обычно не требуется.

## Как работает

Первое сообщение от нового собеседника получает уведомление, что включён AI-автоответчик, и просьбу написать «согласен». Только после согласия сообщения передаются Gemini для формирования ответа.

История последних сообщений хранится только в памяти процесса; согласия сохраняются в consent.json.
