TELEGRAM AI AUTOREPLY BOT

Запуск:
1. Установить зависимости:
   pip install -r requirements.txt

2. Переменные окружения:
   API_ID
   API_HASH
   OPENROUTER_API_KEY

3. Запустить:
   python main.py

Команды в личке:
   /ignore  - добавить текущего собеседника в игнор
   /ignored - снять игнор с текущего собеседника
   /clear   - очистить историю
   /help    - помощь

Команды в группе:
   /dickgroup  - выбрать эту группу для автоматических команд
   /dickstatus - проверить выбранную группу

Автоматическое расписание по времени Казахстана (Asia/Almaty):
   00:00 -> /dick
   00:00 -> фарма
   04:00 -> фарма
   08:00 -> фарма
   12:00 -> фарма
   16:00 -> фарма
   20:00 -> фарма

Выбранная группа сохраняется в dick_group.json.
Игнор пользователей сохраняется в ignored.json.


ФАРМА:
В нужной группе отправь:
   +фарма

После этого именно эта группа будет получать:
   00:00 -> фарма
   04:00 -> фарма
   08:00 -> фарма
   12:00 -> фарма
   16:00 -> фарма
   20:00 -> фарма

Отключить:
   -фарма

Проверить:
   +фарма статус

Группа для фармы хранится отдельно в farma_group.json.
